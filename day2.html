Coworkに日報チェックをお願いする

Coworkモードに切り替えて、以下のプロンプトを送ってみましょう。

📋 コピーして送信（Coworkに）
これから日報の提出チェック作業をお願いします。 【作業内容】 1. ブラウザでChatworkを開いて「【報告】店舗日報」グループを確認してください 2. 以下の4店舗の投稿があるか確認してください ・升屋 ・海神 ・串神坊 ・肉もつ屋 3. 各店舗の提出状況を一覧で報告してください 4. 未提出の店舗がある場合は、以下のテンプレートで リマインドメッセージの下書きを作ってください 【リマインドテンプレート】 [info][title]【◯月◯日（◯）の数値日報について】[/title] 現時点で「【報告】店舗日報 チャット」にて上記報告の確認が出来ていません。 ご確認いただき、上記チャットへご対応をお願いいたします。[/info] ※ Chatworkにログインが必要な場合は声をかけてください。 ※ 送信する前に必ず私に確認してください。

ポイント：Chatworkにログインが必要な場面では、Claudeが止まって許可を求めてきます。パスワードは自分で入力してください。Claudeは認証情報を自動入力しません。

結果を確認する

Coworkが作業を終えたら、以下を確認しましょう。

  1. 4店舗の提出状況が正しく判定されているか
  2. リマインドメッセージの日付が正しいか
  3. 送信先（未提出の店舗）が合っているか

問題なければ、この手順をそのまま次のステップで「スキル」として保存します。修正点があれば、先に直してからスキル化しましょう。

03 — Record a skill

画面を録画してスキル化する

やって見せるだけで、Claudeが手順を覚える（20分）

「Record a skill」とは？ 7/21 新機能

自分が実際にPCで作業している様子を画面録画し、声で説明すると、Claudeがその手順を「スキル」として覚えてくれる機能です。

録画開始
→
自分で作業しながら
声で説明する
→
録画停止
→
スキルとして
自動保存

つまり：プロンプトを書く代わりに、「やって見せる」ことでClaudeに仕事を教えられます。一度教えたら、次からは「日報チェックして」の一言で同じ作業を再実行できます。

録画前の準備 重要

録画の品質は、始める前の準備で決まります。

  1. 関係ないタブ・通知を閉じる — Claudeに余計な情報を見せない
  2. 個人情報・パスワードが映らない状態にする — APIキー等も同様
  3. 声で「なぜその操作をするか」を説明する — クリックだけでは意図が伝わらない
  4. 止める条件・人に確認する条件を口に出す — 「ここは必ず確認してから送信」など
  5. 最初はテストデータで録画する — 本番データは2回目以降で

録画の手順

  1. Coworkタスクの入力欄にある「＋」メニューをクリック
  2. 「Record a skill」（スキルを録画）を選択
  3. 録画が始まったら、日報チェックの作業を最初から実行する
  4. 各ステップで声に出して説明する（下の例を参考に）
  5. 一通り完了したら録画を停止
  6. Claudeがスキルに変換 → 個人ライブラリに保存される

声での説明の例

こんな風に話しながら操作する
「今Chatworkを開いて、【報告】店舗日報のグループに移動しています」 「ここで今日の日付の投稿があるか確認します。升屋は…投稿があるのでOK」 「海神は投稿が見当たらないので、未提出としてマークします」 「次にスプレッドシートに移動して、チェックを入れます」 「未提出の店舗にはリマインドメッセージを送ります。 送信する前に必ず私に確認してください。これ重要です」

スキルを呼び出してみる

保存されたスキルは、次からこう呼び出せます。

📋 スキルの呼び出し方
日報チェックのスキルを実行してください。

スキルは育てるもの：実行結果がおかしかったら「このミスをしないようにスキルを更新して」と伝えれば、Claude自身がスキルを修正します。使いながら精度を上げていきましょう。
